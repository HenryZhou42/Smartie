## v0.9 Beta capture checklist
Use an isolated SMARTIE_DATA_ROOT with synthetic content and no visible keys.
Capture Chat with formatted response, Knowledge Base with citations, Appearance in
light/dark, Tasks, Memory, Files, Automations, Plugins, provider setup and About.
Use a consistent 1440x900 window plus a narrow-window example. Show loading/error
feedback where useful. Do not capture personal file paths, real documents, keys,
or logs. Record native drag/drop and streaming/Stop in a short demo.
